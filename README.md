# "Zombie Siege: The Last Frontier"

Данный проект является двумерным пиксельным Tower Defense'ом, который был разработан на Unity в рамках курсовой работы с октября 2025 по январь 2026 годов. Суть игры заключается в том, что игрок должен в роли "Главковерха" или же "Маршала" организовать оборону города от толп зомби. Для этого используются защитные башни и глобальные улучшения навыков.

## Особенности геймплея

- Пассивное наступление зомби между волнами;
- Несколько волн на каждом уровне;
- Шесть видов врагов;
- Убийства приносят очки опыта и монеты;
- Постепенное открытие новых защитных башен;
- Пять видов защитных башен;
- Пять стадий улучшений на каждую башню (по два пути после 3 этапа на каждый тип);
- Механика глобальных улучшений (4 категории);
- Обучение на первом уровне и элементы сюжетности;
- Меню настроек и статистики;
- Внутриигровой справочник по башням и встреченным врагам.
- Поддержка английского, русского и украинского языков.

## Использованные технологии

- Unity6;
- C#;
- Localization.

## Как запустить

1. Скачать репозиторий.
2. Добавить проект через Unity Hub.
3. Открыть проект.
4. Запустить сцену MainMenu.
5.a. Нажать "Play" в Unity.
5.b. Забилдить проект.

## Ограничения

- Доступна только десктопная версия;
- Имеется только 5 уровней.
- Фон главного меню и меню выбора уровней сгенерированы нейросетью.
